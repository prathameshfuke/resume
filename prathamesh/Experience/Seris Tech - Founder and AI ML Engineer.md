# Seris Tech - Founder and AI/ML Engineer

[[Prathamesh Fuke]] founded [[Seris Tech]], an AI healthcare startup focused on proactive healthcare and elderly assistance technologies.

## Key Initiatives

### HealthSentinel

- [[HealthSentinel]] is an AI-powered community healthcare monitoring system.
- Medical Named Entity Recognition using BERT with LoRA/PEFT.
- Outbreak detection and intelligent clinical data analysis.
- Firebase and React Native deployment.

### AgeWell

- [[AgeWell]] is an AI-powered elderly health monitoring platform.
- Real-time monitoring of SpO2, heart rate, BP, and temperature.
- Prescription OCR and automated medication tracking.
- AI anomaly detection with proactive caregiver alerts.

## Additional Work

- Engineered ensemble classifiers for imbalanced medical datasets.
