# ScoreSight

End-to-end ML system for EPL match and season outcome prediction, built by [[Prathamesh Fuke]].

## Stack

LightGBM, XGBoost, Streamlit.

## Highlights

- Built 54 leakage-safe features.
- Achieved 97.2% accuracy for league winner classification.
- Achieved R = 0.977 for score regression.
