# GyanBit

DIY 8-bit educational console ecosystem built by [[Prathamesh Fuke]].

## Stack

JavaScript, RP2040, MicroPython, React, WebSerial, embedded systems.

## Highlights

- Designed and developed an open-source educational handheld console ecosystem for students aged 12-17, combining custom RP2040 hardware with a browser-based game IDE.
- Built a lightweight JavaScript runtime and transpilation pipeline converting browser-authored JavaScript into executable MicroPython for embedded hardware.
- Developed a real-time OLED simulator, WebSerial flashing system, and custom `bit.*` game API enabling rapid game development on constrained hardware.
- Integrated BYTE Bot, an AI-powered coding assistant trained on runtime APIs, hardware pin mappings, and retro game development workflows.
- Engineered a zero-setup development experience with browser-native deployment and hardware flashing support.
- Winner of Judges Choice Award at HackSprint v7.0.

## Key Stats

- 7 built-in games
- 128x64 OLED runtime
- Approximately 30 FPS runtime loop
- 4-layer embedded runtime architecture
- Full browser-to-hardware workflow
