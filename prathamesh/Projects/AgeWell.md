# AgeWell

AI-powered elderly care and assistive diagnosis platform by [[Prathamesh Fuke]] under [[Seris Tech]].

## Stack

React, Flask, Supabase, Groq, Gemini, OCR, TailwindCSS.

## Highlights

- Developed a full-stack assisted living platform for medication adherence, caregiver coordination, symptom triage, and elderly wellness monitoring.
- Built AI-assisted diagnosis workflows combining conversational symptom extraction, deterministic fallback logic, and structured report generation.
- Integrated OCR-assisted prescription parsing, image-based medical observation using Gemini, and Twilio-based caregiver notification systems.
- Designed role-aware elder and caregiver workflows with Supabase-backed authentication and real-time data persistence.
- Implemented accessibility-first interfaces optimized for elderly usability and simplified interaction patterns.

## Key Stats

- 50+ deployments
- Multi-role healthcare workflows
- OCR plus AI-assisted diagnosis
- Supabase plus Flask architecture
- Structured PDF medical report export
